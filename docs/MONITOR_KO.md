# Monitor

메인 창의 Monitor 탭은 장비 상세 UI가 이미 표시하고 있는 값과 그래프를 모아 보는 읽기 전용 화면입니다.

- DS1052E / MSO7054는 장비 이름마다 개별 카드로 표시합니다.
- OSA, ThermoTek, MDT 및 MDT의 PID를 각각 선택할 수 있습니다.
- `표시 장비 선택`의 체크박스로 카드를 선택합니다. 체크박스 목록은 접을 수 있습니다.
- 카드 높이는 같고, `열 수`로 1~3열을 선택합니다. 화면을 넘는 카드는 스크롤로 확인합니다.
- 그래프는 원본 canvas의 렌더링을 그대로 복제합니다. 축 범위, 단위, 표시 모드, 보정 및 데이터 변환을 추가하지 않습니다. 카드 크기에 맞춰 그림 전체를 비율 유지하여 표시합니다.
- 숫자는 원본 UI의 표시 문자열을 그대로 공유합니다. 연결 상태와 오류 문구도 함께 표시합니다.

모니터를 열거나 체크박스를 바꿔도 장비 연결, 새 조회, 측정 시작, 출력 변경은 일어나지 않습니다. 각 상세 창 또는 workflow에서 기존 측정을 시작해야 값이 갱신됩니다. 원본이 측정을 멈추고 마지막 그래프를 유지하면 모니터도 같은 그래프를 유지합니다. 상세 창을 숨겨도 원본 UI가 받는 갱신은 모니터에 반영됩니다. 모니터는 표시 중에만 0.5초 간격으로 UI 내용을 반영하며 장비 통신 주기는 바꾸지 않습니다.

공개 기본 설정은 `labremote/config/ui/monitor.json`입니다. 체크박스/열 수 변경은 Git에서 제외되는 `labremote/config/ui/monitor.local.json`에 자동 저장합니다. 다른 PC에는 로컬 파일을 별도로 복사하세요.

```json
{
  "columns": 3,
  "selected": [
    "ds1052e/scope_A",
    "mso7054/scope_B",
    "osa/osa_name",
    "thermotek/cooler_name",
    "mdt/mdt_name",
    "pid/mdt_name"
  ]
}
```

이름은 예시입니다. 체크박스에 마우스를 올리면 실제 설정 ID를 확인할 수 있습니다. `selected: null`이면 지원하는 모든 장비, `[]`이면 아무 카드도 표시하지 않습니다. 파일을 직접 수정한 후 `설정 다시 읽기`를 누르면 적용됩니다. 메인 장비 구성에서 생성되지 않은 장비는 모니터가 새로 생성하거나 연결하지 않습니다.
