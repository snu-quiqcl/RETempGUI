# CCD / FPGA 제어 화면

## FPGA 포트

FPGA Manual 화면의 **포트 검색**은 운영체제의 serial port 목록을 조회합니다.
포트 이름, 장치 설명, USB serial을 표시하며 포트를 열거나 출력 명령을 보내지 않습니다.
목록에서 선택하거나 포트 이름을 직접 입력한 뒤 Connect를 누릅니다.
연결에 성공한 포트만 `labremote/config/devices/fpga/ports.local.json`에 장비 이름별로 저장합니다.
다음 실행 때 복원하며 USB serial/VID/PID가 유일하게 일치하면 변경된 COM 번호를 따라갑니다.
USB serial이 없거나 중복이면 추측하지 않으므로 목록에서 직접 선택하세요.
이 파일은 Git에서 제외되며 PC마다 포트 번호가 다를 수 있습니다.

## CCD 촬영

- **Apply exposure / gain**: 입력한 노출 시간과 gain을 카메라에 적용합니다. 촬영 정지 후 사용합니다.
- **Capture frames**: Single / N frames 버튼으로 받을 프레임 수입니다. Live의 속도나 누적 평균 횟수가 아닙니다.
- **촬영 결과 자동 저장 (TIFF)**: Single / N frames의 결과를 선택한 디렉터리에 TIFF로 저장합니다. Live 전체를 기록하지 않습니다.
- **Save TIFF / PNG**: 최신 전체 원본 프레임 한 장을 저장합니다. 화면 배색, 반전, 확대는 원본 데이터에 적용하지 않습니다.

기존 Buffered sequence는 메모리의 최근 프레임들을 여러 페이지 TIFF로 저장하는 옵션,
Detection ROI only는 검출 영역만 잘라 저장하는 옵션이었습니다. 이 두 UI 옵션은 제거했습니다.
기존 workflow의 저장 API는 호환성을 위해 유지합니다.

## 연속 검출과 오븐

1. CCD를 연결하고 검출 threshold, 최소 contour area, 목표 개수, 연속 프레임 수를 설정합니다.
2. **Apply detection / 연속 검출**을 누릅니다. 설정 적용 후 촬영이 정지 상태라면 Live를 시작합니다.
   버튼이 초록색이면 화면 기준 연속 검출 설정이 적용되어 촬영 중이라는 뜻입니다. 포획 성공을 뜻하지는 않습니다.
3. ROI 좌표 입력은 없습니다. 현재 확대·이동하여 보이는 센서 픽셀 영역을 사용합니다.
   영상 밖 여백은 제외하며 반전 설정이 있으면 원본 좌표로 변환합니다.
   화면 영역 변경은 최대 약 150 ms 간격으로 전달합니다. 검출 자체는 카메라 프로세스에서 모든 수신 프레임에 수행합니다.
4. CCD 창을 닫아 숨겨도 마지막 표시 영역으로 촬영과 검출을 계속합니다.
5. 가열하려면 이미지 아래 **Oven ON**을 별도로 누릅니다. 검출 버튼은 오븐을 켜지 않습니다.
   Oven ON은 현재 검출 설정을 적용하고 기존 operation 순서로 EC 오븐·flipper·셔터를 제어합니다.
   목표 이상 개수가 지정한 연속 프레임 동안 검출되면 전류를 단계적으로 내리고 PSU OFF / 셔터 CLOSE를 수행합니다.
6. 오븐 동작 중 확대·이동으로 ROI가 바뀌면 연속 검출 횟수를 초기화합니다.
   변경 이전 대기 프레임은 성공 판정에 사용하지 않습니다. 센서가 전혀 보이지 않는 영역에서는 개수 0으로 처리합니다.
7. 일반 연속 검출에는 시간 제한이 없습니다. **오븐의 기존 600초 제한과 취소·오류 시 종료 정리는 유지합니다.**

Wait for ions / Cancel wait는 원래 CCD 조건을 기다리는 operation의 수동 실행·취소 버튼이며,
그 자체로 오븐을 켜거나 끄는 버튼이 아니었습니다. UI에서 제거했고 기존 workflow API는 유지합니다.
직접 ROI를 지정하는 기존 workflow는 자신의 검출 영역을 유지하며 GUI 확대에 의해 덮어쓰지 않습니다.
오븐 가동 시작 시 기존 촬영 정지·검출 설정·재시작 순서도 유지합니다.

## Configuration과 연결 색상

메인 Configuration의 `oven_psu`, `oven_relay` 항목에 서버에 등록된 이름을 지정합니다.
CCD의 PSU instrument / Relay instrument 입력란은 제거했습니다.
구성의 사용 체크는 그룹 연결 대상이며, 상세 창의 수동 연결은 구성에 지정된 이름을 사용합니다.
구성에 오븐 항목이 없으면 임의의 이름으로 연결하지 않습니다.

CCD Display는 메인 **Configuration → 편집 → CCD Display**에서 설정·저장합니다.
`equipment.local.json`의 선택 항목 `ccd_display`에 자동 레벨, Min/Max, Flip H/V,
Ion markers, 배색을 저장합니다. 기존 구성 파일에는 이 항목이 없어도 기본값으로 동작합니다.
Fit image 버튼은 제거했으며 카메라 연결 시 자동으로 전체 센서 영역을 맞춥니다.

메인 장비 그룹 버튼은 전부 연결되면 초록색, 일부 연결되면 황색입니다.
CCD/오븐/FPGA 연결 버튼도 성공 시 초록색으로 표시합니다.
서버 장비 검색 버튼의 초록색은 마지막 목록 조회 성공이며 지속적인 서버 heartbeat는 아닙니다.
주소를 바꾸거나 다시 조회하여 실패하면 상태 색상을 갱신합니다.
