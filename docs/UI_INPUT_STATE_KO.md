# UI 입력값 자동 저장

정상 종료를 확정하면 `labremote/config/ui/input_state.local.json`에 입력값을 저장하고 다음 실행에서 복원합니다. `*.local.json` 규칙으로 Git에서 제외됩니다. 다른 컴퓨터로 마지막 입력값을 옮기려면 이 파일을 직접 복사하세요.

숫자 입력, 일반 텍스트 입력, 선택 목록, 체크박스/라디오버튼, 슬라이더, 일반 다중행 입력을 저장합니다. 장비명 및 입력 필드별 키를 사용하므로 EA/EC·장비별 입력을 분리합니다. 별도 상세 창과 나중에 생성되는 장비 패널도 포함합니다. 장비 조회 후 채워지는 목록은 저장된 선택지가 실제로 나타났을 때 복원합니다.

복원 중 Qt 입력 신호를 차단합니다. 연결, 출력 설정, 촬영, PID, workflow는 자동 실행하지 않습니다. 화면 값 복원은 장비 설정 적용과 다릅니다. 장비를 연결한 뒤 실제 readback이나 명시적인 설정 불러오기를 실행하면 해당 동작이 화면 값을 갱신할 수 있습니다.

읽기 전용 결과, 로그, 암호 입력, 연결/실행 버튼 상태는 저장하지 않습니다. Workflow Python 코드와 Queue 작업 목록, 장비 구성 파일 편집은 기존 전용 저장/불러오기 기능을 사용합니다. 이 기능은 입력 폼의 마지막 값 저장이며, 실험 프로그램이나 장비 구성 파일을 대체하지 않습니다.

저장은 종료 정리 전에 한 번 수행합니다. 강제 종료/프로세스 충돌은 저장 시점이 아닙니다. JSON이 손상되면 기존 기본값으로 시작하고 이벤트 로그에 이유를 기록합니다. 정상 저장 시 임시 파일 작성 후 교체하여 중간 파일 손상 가능성을 줄입니다. 초기화하려면 GUI가 닫힌 상태에서 `input_state.local.json`을 다른 이름으로 옮기세요.
