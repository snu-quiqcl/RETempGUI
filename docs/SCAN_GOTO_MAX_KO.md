# Scan 드래그 확대와 Go to Max

네 개 motor scan 탭에서 동일하게 사용할 수 있습니다.

- **Drag zoom**을 켜고 XY 이미지 위에서 마우스 왼쪽 버튼을 누른 채 사각형을 그리면 확대합니다. 새 측정점이 표시되어도 확대 범위를 유지합니다.
- **Reset XY zoom** 또는 그래프 더블클릭으로 전체 범위로 복귀합니다. Drag zoom을 끄면 드래그 확대만 비활성화됩니다.
- **Go to Max**는 유한한 실제 측정값 중 가장 큰 값의 위치로 이동합니다. Gaussian fitting 중심을 사용하지 않습니다. 동률이면 배열 순서(Z, Y, X)의 첫 측정점을 선택합니다.
- XY scan: X/Y만 이동하며 Z는 변경하지 않습니다.
- Z scan: 모든 Z 평면에서 최대값을 찾아 Z → X → Y 순서로 이동합니다. 현재 표시한 평면이나 확대 범위로 검색을 제한하지 않습니다.
- 중단된 scan도 측정된 유효 점이 있으면 사용할 수 있습니다. 미측정 NaN은 제외합니다.
- 이동 좌표와 단위 환산은 측정 당시 값입니다. 이후 Start/End/Step을 편집해도 최대값 위치는 바뀌지 않습니다.
- scan 실행 중 또는 대상 모터에 다른 작업이 있으면 이동할 수 없습니다. 모든 대상 모터의 연결·상태·범위를 먼저 확인한 뒤 이동합니다. scan 이후 다른 서버/장비로 연결이 바뀌면 재측정을 요구합니다.
- 이동은 기존 operation 큐와 readback을 사용합니다. Stop / save partial 버튼은 Go to Max 실행 중에도 취소를 요청합니다. 진행 중인 장비 통신/이동 반환을 기다리며, 이동한 축을 자동으로 원위치 복귀하지 않습니다.
