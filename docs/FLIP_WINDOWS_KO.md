# Flipper 버튼과 장비 창

## Flipper

기존 선택 장비 연결 버튼은 드롭다운의 한 장비만 연결하는 기능이었습니다.
이제 서버 목록의 실제 이름별로 연결, 연결 해제, 위치 읽기, Position 1, Position 2 버튼을 표시합니다.
공유 이동 버튼과 상태 테이블은 표시하지 않습니다. Position 버튼의 초록색은 마지막 정상 읽기로 확인된 위치입니다.
이동·읽기 진행 중에는 해당 장비의 버튼을 잠그고 위치 색상을 미확인 상태로 표시합니다.

1. 메인 서버 주소를 확인하고 Flipper 화면에서 서버 목록을 불러옵니다. 메인 서버 장비 검색 결과도 공유합니다.
2. **Flipper 전체 연결**은 조회한 모든 flipper를 하나씩 연결합니다. 이미 연결된 장비는 건너뜁니다.
3. 각 카드의 Position 1/2는 그 카드에 적힌 장비에만 operation을 전송합니다.
4. 장비 하나의 연결 오류는 카드 아래에 표시하며 나머지 장비는 계속 연결합니다.
   공통 서버 응답 timeout이면 남은 연결을 중지하여 요청을 계속 보내지 않습니다.

EA/EC 경로 설정 및 수동 경로 적용 버튼은 화면에서 제거했습니다.
기존 `labremote/config/operations/flipper_routes.local.json`의 자동 경로 매핑과 포획 workflow는 유지합니다.
Flipper 전체 연결과 Position 버튼 사용은 서버 드라이버/YAML 변경이 필요하지 않습니다.
목록에 5대가 아닌 일부만 표시되면 서버 등록 이름·드라이버 메타데이터를 확인해야 합니다.

## 창과 상단 장비 메뉴

메인 메뉴의 **장비**에서 RF, 미라, CCD, FPGA, 오실로스코프, 기타 창을 열 수 있습니다.
개별 장비 이름을 선택하면 기존 상세 창 안의 해당 장비로 이동합니다. Flipper와 오븐도 바로 열 수 있습니다.
창을 열 때 새 worker를 만들거나 장비를 자동 연결하지 않습니다.

상세 창은 Windows에서 메인창 위에 고정되는 부모 소유 창 대신 독립 창으로 생성합니다.
메인창을 클릭해 앞으로 가져올 수 있고 상세 창 상단의 메인창 메뉴로도 돌아갈 수 있습니다.
상세 창 닫기는 숨기기이며 연결·촬영은 유지합니다. 메인창 종료 시 기존 worker 종료 정리를 마친 뒤 모든 창을 닫습니다.

## CCD 이미지 수신과 갱신

CCD는 PlotWidget, ViewBox, ImageItem 및 이온 표시 객체를 한 번 만들고 재사용합니다.
새 프레임에서는 ImageItem의 이미지 배열과 이온 표시 좌표를 갱신합니다. 매 프레임 축을 지우거나 창을 새로 만들지 않습니다.
카메라 연결/첫 표시 때 전체 프레임에 맞추고, 이후 사용자가 지정한 확대·이동 범위를 유지합니다.

카메라 프로세스는 카메라에 설정된 전체 촬영 프레임을 받습니다. 기본 카메라 설정이 전체 센서이면 전체 센서 프레임입니다.
기존 SDK ROI가 설정되어 있으면 그 촬영 크기를 사용합니다. UI의 확대/이동은 카메라 SDK ROI를 변경하지 않습니다.
수신 프레임 중 현재 화면 범위만 소프트웨어로 잘라 이온을 검출합니다.
미리보기는 전체 프레임을 공유 메모리의 최신 한 슬롯으로 전달하고 UI는 약 33 ms 주기로 읽습니다.
화면에서 확대해도 USB로 받는 프레임 크기는 줄어들지 않습니다.
