# 탭 입력 기본값 설정

`input_defaults.json`이 탭 입력칸의 공통 기본값 파일입니다. 실행 중 자동으로
덮어쓰지 않습니다. 파일을 편집한 뒤 GUI를 다시 실행하세요.

우선순위 (높은 순서):

1. `input_state.local.json`에 저장된 해당 입력칸의 마지막 값
2. `input_defaults.json`의 `inputs`에 지정한 개별 입력칸 값
3. 같은 파일의 `families`에 지정한 장비 계열 공통 값
4. 설정이 누락되거나 잘못된 경우에만 기존 위젯/장비 설정의 초기값

기존 생성자의 값은 설정 파일 누락 시 복구용으로 남아 있습니다. 실제 시작
화면의 기본값은 이 파일로 변경할 수 있으며, Python 코드를 수정할 필요가 없습니다.
허용 범위, 단위 변환, 하드웨어 보호 제한은 기본값과 별개입니다.

## 편집 예

모든 DAC의 Step 기본값을 0.02 V로 바꾸려면 `families` → `dac` → `step`을 수정합니다.

```json
"step": {"kind": "number", "value": 0.02}
```

EA만 0.05 V로 사용하려면 최상위 `inputs`에 다음 항목을 추가합니다.

```json
"device/dac/dac_ea/step": {"kind": "number", "value": 0.05}
```

그 입력칸에 이전 저장값이 있으면 이전 값이 계속 우선합니다. 새 기본값을
적용하려면 **GUI를 종료한 상태에서** `input_state.local.json`의 `inputs`에서
해당 키만 제거하세요. 전체 마지막 값 파일을 삭제할 필요는 없습니다.

`kind`는 `number`(숫자), `text`(문자), `choice`(콤보박스 항목 문자열),
`check`(true/false), `multiline`(여러 줄 텍스트) 중 하나입니다. `value`만 바꾸는
것을 권장합니다. 범위 밖 숫자나 잘못된 형식은 경고하고 적용하지 않습니다.
콤보박스는 항목이 장비 검색 후 추가되는 경우 그때까지 복원을 기다립니다.

`input_defaults.catalog.json`은 입력칸 전체 키와 숫자 범위·선택 항목을 확인하는
참고 목록입니다. 실행 설정은 `input_defaults.json`입니다. 빈 선택 목록은
검색/실행 상태에 따라 나중에 채워지는 항목입니다.

## 경로 및 장비 이름

text 값은 다음 토큰을 지원합니다.

- `${PROJECT_ROOT}`: 현재 설치된 프로젝트 디렉터리
- `${TODAY}`: 실행 PC의 오늘 날짜 (YYYY-MM-DD)
- `${INSTRUMENT}`: 해당 장비의 등록 이름 (새 Motor의 접속 대상을 다른 Motor로 바꾸지 않음)

## 저장과 장비 제어

마지막 입력값은 종전처럼 정상 종료 시 `input_state.local.json`에 저장합니다.
기본값 config는 종료 시 변경하지 않습니다. 기본값 적용과 마지막 값 복원은
입력 이벤트를 차단해 수행하므로 Apply, Init, Move 등의 장비 명령을 보내지 않습니다.
실제 장비 값을 조회하면 기존 탭 로직에 따라 측정/상태 표시가 갱신될 수 있습니다.

Motor·HOM·Entanglement 및 분리된 상세 창도 기본값/마지막 값 관리에 포함됩니다.
기존 입력 키로 저장된 값이 있으면 가능한 기존 위젯 키를 찾아 우선 복원합니다.
새로 추가한 장비 탭은 계열 기본값을 사용하고, 기존 장비별 값은 `inputs`로
재정의할 수 있습니다.

이 파일은 UI 입력칸을 관리합니다. DAC offset/매핑, 장비 연결·출력 제한,
시퀀스/Queue의 사용자 데이터 행, 프리셋, 편집 중인 Python 소스 문서는 기존
전용 설정·저장 파일을 사용합니다. 비밀번호와 읽기 전용 상태 표시도 제외합니다.
일회성 편집 대화상자의 데이터는 해당 작업의 기존 저장 규칙을 따릅니다.
